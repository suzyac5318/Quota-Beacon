## 发布门槛

发布前应满足：

- 前端测试、前端构建、Rust 测试通过。
- Windows CI bundle artifact 与 SHA-256 成功生成。
- Windows 实机完成安装、启动、托盘、拖动、锁定、语言切换、退出验证。
- 严重和高风险问题清零。
